# Точный Масштаб

Расширение для браузера Chrome, которое позволяет удобно изменять масштаб страницы с шагом 1%.

![Скриншот](screenshot.png)

## Особенности
- 🔍 Ползунок масштаба с шагом 1%
- ➕➖ Кнопки «+» и «-» с шагом 1%
- ⌨️ Ручной ввод точного значения в процентах
- 🔄 Кнопка быстрого сброса на 100%
- 💾 Автоматическое запоминание масштаба для каждого сайта отдельно

## Установка (без Chrome Web Store)
1. Скачайте архив с кодом (зелёная кнопка `Code` → `Download ZIP`).
2. Распакуйте его в отдельную папку.
3. Откройте в браузере `chrome://extensions`.
4. Включите **«Режим разработчика»** (в правом верхнем углу).
5. Нажмите **«Загрузить распакованное расширение»** и выберите папку.
6. Готово! Иконка появится в панели браузера.
